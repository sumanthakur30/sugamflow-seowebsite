SugamFlow

School management software

SugamFlow includes a School ERP vertical for campus operations. It uses the same platform identity and subscription model as shops and clinics, with a school-oriented workspace rather than a medical-shop counter.

Campus operations

School tenants are set up for administration work such as admission, fees, attendance, exams, and related campus modules (for example hostel or transport when those modules are enabled for the school). Parent or student portals, when used, are not a public directory on sugamflow.com.

Same platform, different workspace

Staff still authenticate through the platform login model. School website CMS, when assigned, is a platform Website module — not a second identity product.
